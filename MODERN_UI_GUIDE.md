# 🚀 auto2tesst v2.0 - Modern UI Guide

## ✨ Что нового?

### Полностью переработанный интерфейс

**auto2tesst v2.0** - это не просто обновление, это полная трансформация!

#### 🎨 Современный дизайн 2025 года

- **Темная тема по умолчанию** с переключателем Light/Dark
- **Минималистичный UI** без лишних элементов
- **Плавные анимации** и hover-эффекты
- **Адаптивный layout** - все растягивается красиво
- **Единое окно** вместо множества popup-ов

#### 🧩 Новые компоненты

1. **Toast Notifications** 🍞
   - Заменили все надоедливые messagebox.showinfo()
   - Появляются внизу справа
   - Автоматически закрываются через 3-5 секунд
   - Цветовое кодирование: зеленый=успех, красный=ошибка, синий=инфо, оранжевый=предупреждение

2. **Collapsible Sections** 📁
   - Настройки сворачиваются/разворачиваются одним кликом
   - Нет больше бесконечных скроллбаров
   - Чистый и организованный интерфейс

3. **Сайдбар навигация** 🧭
   - Быстрое переключение между разделами
   - Import → Run → Logs → Settings
   - Визуальная индикация активной страницы

4. **Цветовая подсветка логов** 🎨
   - [INFO] - синий
   - [OK]/[SUCCESS] - зеленый
   - [WARNING] - желтый/оранжевый
   - [ERROR] - красный
   - [SMART CLICK] - фиолетовый
   - [ANSWER] - бирюзовый
   - [RANDOM] - оранжевый
   - [POPUP] - лиловый

#### ⌨️ Горячие клавиши

- **Ctrl+I** - Import code
- **Ctrl+R** - Run script
- **Esc** - Stop execution
- **Ctrl+S** - Save settings
- **Ctrl+L** - Clear logs

#### 📂 Drag & Drop (планируется)

Просто перетащите .py файл в окно для импорта!

## 🎯 Использование

### Быстрый старт

1. **Установка зависимостей:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Запуск:**
   ```bash
   python main.py
   ```

3. **Импорт кода:**
   - Нажмите "📂 Open Python File" или Ctrl+I
   - Или "📋 Paste from Clipboard" для вставки из буфера
   - Код автоматически распарсится и появится в редакторе

4. **Настройки:**
   - Перейдите в ⚙️ Settings
   - Разверните нужную секцию (API, SMS, Proxy, CSV)
   - Заполните поля
   - Нажмите "💾 Save All Settings"

5. **Запуск:**
   - Перейдите в ▶️ Run Script
   - Нажмите "▶️ START"
   - Следите за прогрессом в логе

## 🔧 Кастомизация

### Изменить цвета

Отредактируйте `src/gui/themes.py`:

```python
class ModernTheme:
    DARK = {
        'bg_primary': '#0a0e27',      # Ваш цвет
        'accent_primary': '#6366f1',  # Ваш акцент
        # ... и т.д.
    }
```

### Добавить новую страницу

1. Создайте метод `create_yourpage_page()` в `modern_main_window.py`
2. Добавьте кнопку в сайдбар
3. Добавьте в `self.pages`

### Создать новый компонент

Добавьте файл в `src/gui/components/` и импортируйте в `__init__.py`
